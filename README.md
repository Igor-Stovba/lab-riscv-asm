# Lab RISC-V asm

## Вариант задания

| Вариант задания                                          |
| ---------------------------------------------------------------------- |
| Найти сумму элементов массива. (N =4, M = 4) |

## Результаты работы

- **sum_array.S** — программа на RISC-V ASM
- **func.c** — программа на Си
- **func.dump** — дамп-файл программы на Си

## Сборка

Сборка примера на Си в полностью настроенном окружении выполняется с использованием GNU Make.

Для этого, находясь в каталоге с `Makefile`, необходимо выполнить команду:

```bash
make
```
